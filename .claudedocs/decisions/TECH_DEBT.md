## TD-001 · اسمٌ مضاعَف فقد سببَه: `CatalogService` / `catalog_service_service.py`

**سُجِّل:** ٢٠٢٦-٠٩-١٦ · **القرار:** سلمان — مؤجَّل، ولا يُعطّل إطلاقَ ميزة البضاعة.

### الدَّين

الموديل سُمّي `CatalogService` بدل `Service`، والخدمةُ سُمّيت `catalog_service_service.py` —
والسببُ مكتوبٌ في `prisma/schema.prisma:534`:

> *«Named "CatalogService" (not the shorter "Service") because a completely unrelated `Service`
> model already exists for smar's property booking add-ons»*

**وذاك الموديل حُذف** في `2d464d7` (٢٠٢٦-٠٩-٠٧) مع `service_service.py` و
`booking_service_service.py`، حين رُحِّل جدولُ `services` القديم إلى `catalog_services`.

```
⇒ التصادمُ الذي فرض الاسمَ المضاعَف: **زال**.
⇒ والاسمُ باقٍ، وتبريرُه يُحيل إلى ملفٍّ لا يجده أحد — وهو ما جعل سلمان يشكّ في البنية كلِّها
  بينما البنيةُ سليمة (Q1: الانفصالُ صحيحٌ ولا يُدمَج).
```

### لماذا يُؤجَّل

```
الكلفة المقيسة:  migration لإعادة تسمية جدول  +  ~٤٥ ملفّاً تذكر الاسم
                 (app/api 10 · app/services 9 · app/repositories 6 · scripts 20 · frontend 10)
والمكسب:         وضوحُ قراءةٍ فقط — صفرُ تغييرٍ سلوكيّ
```

**ولا يبرّر تعطيلَ ميزةٍ للمالك.** والضررُ الحقيقيُّ (docstring يُحيل إلى ملفٍّ محذوف) **أُزيل
بالفعل** في ٢٠٢٦-٠٩-١٦: نصُّ `catalog_service_service.py` صار يشرح المعانيَ الثلاثةَ لكلمة
«service» ويقول صراحةً إنّ سببَ التسمية تاريخيٌّ وزال.

### شرطُ السداد — قابلٌ للفحص

```
يُفتَح حين يتحقّق أحدُ الاثنين:
  ١  عملٌ كبيرٌ يلمس هذه الملفّاتِ أصلاً (إعادةُ تنظيم الكاتالوج مثلاً) ⇒ التسميةُ تركب معه بلا كلفةٍ إضافيّة
  ٢  أو يتكرّر الالتباسُ مرّةً ثانيةً موثَّقة  ⇒ وقاعدةُ تصعيد النمط (`rules/team-roles.md`) تجعله مرشَّحاً

ولا يُفتَح لأنّه «يبدو أنظف».
```

### والمفرداتُ الثلاث، مثبَّتةً حتى ذلك الحين

```
service (١)  منتجُ المنصّة        platform_services · client_services · require_service()
service (٢)  ما يبيعه المحلُّ لزبونه  CatalogService
service (٣)  طبقةُ الكود           app/services/*.py
```

**تُستعمل هذه المفرداتُ في كلّ نصٍّ وcommit جديد** — كما فُعل مع `owner` / `admin` / `barber`
(`rules/backend/security.md` §4). والتسميةُ في الكود تتبع لاحقاً، لا العكس.
