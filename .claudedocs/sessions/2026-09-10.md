### 2. Key Technical Concepts

- Multi-tenant SaaS: FastAPI + Prisma (prisma-client-py) + Supabase Postgres (Frankfurt `eu-central-1`) + React/Vite on Railway
- 4-layer architecture (Routes → Services → Repositories → DB); every query filtered by `clientId`
- Permission model slices: `require_roles` (legacy) vs `require_permission` (migrated); `MIGRATED_AREAS`; invariant I1 (permissions NULL = legacy account), I4 (deny-by-default), I5 (`x.write` satisfies `x.read`), I7 (server-side permission resolution only)
- WhatsApp Cloud API: 24-hour customer-service window, free-form `type:"text"` vs `type:"template"`, `wamid`, `statuses[]` callbacks
- Meta WhatsApp Flows, `APPOINTMENT_BOOKING` category, Embedded Signup, per-tenant WABA/Phone Number ID
- `_fire_and_forget` + "never raises" notification contract
- Phone normalization: storage WITH country code, entry WITHOUT (country selector)
- Playwright MCP browser verification protocol
