## 🔧 Technical Decisions Made

- **Recommendation ≠ Decision, tested for real**: when a pattern repeated 3 times, the instinct was
  to write the ADR immediately — Salman explicitly held the line: state the Principle, defer the
  ADR, because the evidence proves the *problem* repeats, not that a *solution* has converged. First
  real test of this discipline against something genuinely tempting to fast-track.
- **`reviews/` immutability applied to itself**: corrections to the Architecture Checkpoint Review
  went into a new addendum file, not an edit to the original — the rule this session wrote into
  `architecture-review-loop.md` earlier this week, followed under its own first real pressure to
  break it.
- **Ownership before Persistence (ADR-0004)**: the deciding question for any new concept is "who
  owns this" (Business/Experience/Platform/External Provider), with Database-vs-JSON-vs-Service
  demoted to an implementation-level question asked only after ownership is settled.
- **Brand Name stays Dashboard-only, not forced Inline**: a real absence of a rendered public
  surface, not a limitation — confirmed the Editing Engine's actual goal is "edit from the most
  suitable Interface," not "everything Inline."
