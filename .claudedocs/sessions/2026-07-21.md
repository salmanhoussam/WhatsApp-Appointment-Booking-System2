| **beit-al-fakhar `/store` infinite loading spinner (the real, final bug)** | `frontend/src/hooks/useCatalog.js` | `mountedRef` never reset to `true` in the effect's setup — only the cleanup set it `false`. React 18 StrictMode's dev-mode mount→cleanup→remount cycle permanently latched it `false` for the component's real lifetime, so every `if (mountedRef.current)` guard silently no-op'd forever: fetches succeeded, state updates were skipped | Reset `mountedRef.current = true` in the effect's setup. Verified via direct headless-Chrome CDP capture (console trace + a real screenshot showing all 4 category pills + all 25 real plate photos rendering) |

**Important finding, not a bug fix**: the Supabase pooler flakiness and the `mountedRef` bug are two independent, unrelated real causes of similar symptoms — neither explained the other. Both were found, both were fixed/mitigated separately, per the new "Independent Causes Are Allowed" rule.
