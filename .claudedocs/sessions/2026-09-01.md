## 🔎 Investigation — Header Login/Register Icon (2026-09-01)

**Confirmed Findings:**

1. **تسجيل الدخول/إنشاء حساب للعملاء مكسور بالكامل — 404 حقيقي، مش مجرد لون.**
   `GlobalAuthModal.jsx` بيستدعي `POST /{slug}/auth/register` و `/{slug}/auth/login`. البحث بكل
   `app/api/v1/public/` طلع إنه المسار الوحيد الموجود فعلياً هو `/moments/auth/register` (بملف
   `moments.py`، prefix ثابت `/moments`، خاص بنظام "Creator accounts" لصفحات المناسبات — نظام
   تاني كلياً، مالوش علاقة بعملاء التنانت). ولا يوجد أي route عام `/{slug}/auth/register` لعملاء
   حقيقيين. تحقق حي عبر السيرفر المحلي:
   ```
   curl -X POST http://127.0.0.1:8000/api/v1/public/rk/auth/register -d '{...}'
   → HTTP 404 {"success":false,"error":{"code":"NOT_FOUND",...}}
   ```
   يعني: ولا عميل واحد قدر يسجل حساب أو يدخل من أي صفحة تنانت حقيقية لحد اليوم — الميزة كانت
   موجودة بالواجهة بس مش موصولة بأي backend حقيقي.

2. **اللون ذهبي hardcoded بالكامل** — `GlobalAuthModal.jsx` (مش نفس الملف يلي صلّحته اليوم
   بالهيدر) فيه `#d4a853`/`rgba(212,168,83,...)` بكل مكان: أيقونات، حدود input، الأزرار، الخط
   العلوي — ولا شي مربوط بـ `config.primary_color`. منفصل تماماً عن تصليح TenantHeader.jsx.

3. **رابط "بوابة الموظفين والإدارة" داخل المودال العام** — `GlobalAuthModal.jsx:388-414`، بيعمل
   `window.location.href = 'https://demo.salmansaas.com'` — ظاهر لأي زبون بفتح المودال، على أي
   تنانت. سلمان طلب صراحة إزالته: الوصول للداشبورد حصري عبر رابط/QR code يبعته هو، مش discoverable
   من الصفحات العامة.

**قرار مطلوب من سلمان:** رقم 1 (تسجيل الدخول الحقيقي) نظام backend كامل غير موجود أصلاً (لا
schema، لا service، لا route) — مش تصليح سريع متل 2 و3. لازم قرار صريح: نبنيه اليوم كـ scope
حقيقي، ولا نأجله ونكتفي اليوم بـ 2+3 (لون + إزالة رابط الأدمن)؟
