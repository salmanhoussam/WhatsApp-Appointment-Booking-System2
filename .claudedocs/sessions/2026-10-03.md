### 2. Key Technical Concepts

- **The unreachable capability** (`evolution/unreachable-capability.md`): built, correct, tested,
  zero entry points. Instances 8–12 found across these two days.
- **A check that fails for the wrong reason has measured nothing** — and its worst form is when the
  wrong reason lands on the side the caller wanted (`evolution/test-evidence-discipline.md`, family
  now **22** instances).
- **Every control carries a control of its own** — proving in the same run that the check can fail.
- **Sealed read-only reader**: `conn.set_session(readonly=True)` + a write probe against a column
  that **exists** (`sort_order`), so refusal is attributable to the seal.
- **Supabase Storage returns 400, not 404**, for a missing object; absence must be said twice
  (folder enumeration **and** a settled 400).
- **Platform-wide vs tenant-scoped invariants**: caracas holds 0 order lines, so a tenant-scoped
  check reads 0→0 and can never fail; `store_order_items` is counted platform-wide and re-counted
  *inside* the transaction.
- **SKU as a stable key**: `@@unique([clientId, sku])`; `app/core/sku.py` is the one normalisation
  boundary; A-Q5 (never re-used) makes an opaque `ITEM-xx` permanent; A-Q6 (archived on retire,
  stamping `-ARCHIVED-<epoch>`) is the discriminator between deliberate retirement and cascade
  damage.
- **Migration on a mutable predicate**: selecting on `is_active` then changing `is_active` later
  produces *newly eligible* rows, not failed ones — invisible to each script individually, caught
  only by a platform-wide recount.
- **framer-motion**: `layout` + `AnimatePresence mode="popLayout"` makes tiles travel between
  columns; `prefers-reduced-motion` honoured throughout.
- **frame-sequence canvas vs `video.currentTime`**: the RK lab measured 121 seeks per scroll for
  continuous seek vs 4 for the hybrid, and recommended **against** continuous seek.
- **Config shape**: the public tenant config is **unwrapped**; top level carries
  `whatsapp_number`, `primary_color`, `name_ar`; the nested `config` blob carries `catalog_layout`,
  `logo_url`, `content`, `hero`.
- **Public config cache** with a TTL in `public_service.py` — a backend change is not visible
  instantly.
