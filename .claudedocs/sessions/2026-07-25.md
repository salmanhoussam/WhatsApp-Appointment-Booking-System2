## 🐛 Bugs Fixed

| Bug | File | Root Cause | Fix Applied |
|-----|------|------------|-------------|
| **Cross-tenant cart leak (Priority 1 carry-forward)** | `useGenericStore.js` | `persist` middleware wrote `cartItems` under one fixed global `localStorage` key (`generic-cart`), not scoped per tenant | Custom slug-scoped storage adapter (`{slug}_generic-cart`) + `setConfig` now detects a real tenant switch and clears cart/session state |
| **False-positive cart-clear on every fresh page load** (found *while verifying* the fix above) | `useGenericStore.js` | `useTenantConfig()`'s loading-state placeholder (`DEFAULT_CONFIG`, hardcoded `slug: 'unknown'`) looked like a "previous tenant" the instant real data arrived, wiping a legitimately-persisted cart | Excluded the literal string `'unknown'` from ever counting as one side of a real tenant change |
| **`mountedRef` never reset to `true` on effect setup — 6 files** | `FeaturedItemsSection.jsx`, `CategoriesGridSection.jsx`, `OverviewTab.jsx`, `ActivityFeed.jsx`, `OrdersTab.jsx`, `ReservationsTab.jsx` | Same bug class as `useCatalog.js` (fixed 2026-07-21): React StrictMode's dev-mode mount→cleanup→remount permanently latches `mountedRef.current` to `false`, so `if (mountedRef.current)` guards silently no-op forever — fetches succeed but state never updates, UI stuck on loading skeletons forever | Reset `mountedRef.current = true` inside the effect's setup, not just the `useRef(true)` initializer |
| Empty "خدماتنا" section on the real page | (was the `mountedRef` bug above, same fix) | `FeaturedItemsSection` fetched real catalog data successfully but never left its loading state | Fixed by the `mountedRef` fix + real catalog content added |
| Cloudflare Pages 404 on the static preview's root URL | (deployment structure, not code) | Zip had `index.html` nested inside an `RK/` folder — Cloudflare needs `index.html` at the zip's root for `/` to resolve | Rebuilt zip with `index.html` at the top level |
| `position: sticky` broken in the static preview | `cloudflare-preview/RK/index.html` | `overflow-x: hidden` on `html`/`body` silently breaks `position: sticky` for a descendant (real, reproducible CSS interaction) | Removed the `overflow-x: hidden` rule |
| Story-experience overlay text never appearing in the static preview | `cloudflare-preview/RK/index.html` | Progress formula used `height - viewport` (the lab's convention) while the real chapter `holdStart`/`holdEnd` values were calibrated for the *production* component's semantic (full height as denominator) | Matched the production formula exactly |
