## 🔧 Technical Decisions Made

- **anas.html hero: layered video (blurred backdrop + sharp centered "window") instead of forced cover-fit** — the source footage's native aspect ratio (portrait, 478×850) is fundamentally mismatched to a wide desktop hero; forcing `object-fit:cover` was the root cause of the reported blur, not a codec/quality issue.
- **Salman Local AI Agent is a standalone product, not a SalmanSaaS replacement** — lives in `local-agent/` inside this same repo for now (explicitly deferred splitting into a separate repo until Phase 1/2 prove out), talks to a *local* database so client data never has to leave their machine, and uses a fully local LLM (Ollama) so not even prompts leave the machine.
- **Plugin architecture over "connector"** — a generic `execute(action, payload)` interface was adopted specifically because future integrations (Odoo, SAP, Square, a local POS) aren't necessarily databases with CRUD semantics; "connector" implied a narrower scope than what's actually planned.
- **SQL portfolio piece kept honestly labeled as illustrative** — no real Coursera lab data exists in the uploaded material yet (verified via full-folder grep + screenshot review); fabricating realistic-looking data would misrepresent the user's actual coursework.
