`plans/fleet-management-plan.md`: ٤٤٨ سطراً، وحالتُه المُعلَنةُ في سطرِه الثالث: **«بانتظار موافقة

### ف-٢ · صفرُ صفٍّ في الستّة — مقيسٌ بقارئٍ مختوم

```
fleet_vehicles 0 · fleet_drivers 0 · fleet_trips 0
samsara_events 0 · driver_alerts 0 · driver_consents 0
```
الختمُ مُثبَتٌ بكتابةٍ مرفوضةٍ قبل أيِّ قراءة. ⇒ الوحدةُ **مبنيّةٌ ولم تُستعمَل قطّ**.

### ف-٣ · 🔴 سرُّ الـwebhook فارغٌ في الإنتاج، وبلا حارسِ إقلاع

```python
# app/adapters/samsara_adapter.py:23
_WEBHOOK_SECRET = os.getenv("SAMSARA_WEBHOOK_SECRET", "")   # ← افتراضٌ فارغ
```

```
متغيّراتُ SAMSARA في .env:  صفر   ⇒ القيمةُ الفعليّةُ الآن = ""
حارسُ إقلاعٍ يرفض التشغيلَ بسرٍّ فارغ:  لا يوجد
```

**والنمطُ موجودٌ في المشروعِ أصلاً**: `app/core/config.py:120,122` يرفعان `ValueError` عند الإقلاع
لـ`SECRET_KEY` و`WHATSAPP_VERIFY_TOKEN`. ⇒ **هذا السرُّ تُرك خارجَ حمايةٍ قائمة، لا أنّ الحمايةَ
غيرُ موجودة.**

**لماذا يهمّ:** `hmac.new(b"", payload, sha256)` قابلٌ للحسابِ من أيِّ أحدٍ يخمّن أنّ المفتاحَ
فارغ — وهو أوّلُ ما يُجرَّب. الحارسُ **مكتوبٌ جيّداً** (رأسٌ مفقودٌ ⇒ 403 · مشوَّهٌ ⇒ 403 · إعادةُ
تشغيلٍ بعد ٣٠٠ث ⇒ 403 · `compare_digest`) — **ومفتاحُه هو الثغرة، لا منطقُه**.

### ف-٤ · والتينانتُ يُحَلّ من جسمِ الطلب

```python
org_id = payload.get("organizationId") or payload.get("orgId") or os.getenv("SAMSARA_DEFAULT_SLUG","")
...
client = await prisma_client.client.find_first(where={"slug": org_identifier})
```

الـslug يأتي من **حمولةٍ يتحكّم بها المُرسِل**. مع ف-٣، يصير الأثرُ النظريّ: كتابةُ أحداثِ أسطولٍ
منسوبةً إلى **أيِّ تينانت**. والمسارُ حيٌّ ومُثبَتٌ على الإنتاج:

```
POST /api/v1/webhooks/samsara  (بلا توقيع)  →  403 "Missing X-Samsara-Signature header"
```

## ما لم أفعله — وحدُّه مقصود

**لم أزوّر توقيعاً ولم أرسل حمولةً موقَّعةً إلى الإنتاج.** إثباتُ الاستغلالِ من طرفٍ إلى طرفٍ
يتطلّب كتابةَ صفٍّ في قاعدةِ الإنتاج بطلبٍ مُزوَّر — وهذا استغلالٌ لا قياس، والبوّابةُ مغلقة.

⇒ ف-٣ و ف-٤ **مُثبَتتان على مستوى الكودِ والإعدادِ والمسارِ الحيّ**، و**الاستغلالُ العمليُّ
غيرُ مُختبَر** بقصد. هذا الفرقُ مذكورٌ لا مطموس.
