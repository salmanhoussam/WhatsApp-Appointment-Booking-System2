# غيابُ السعر ليس سعراً يساوي صفراً — تحقيقُ ⑥

**التاريخ:** 2026-10-03 · **النوع:** تحقيقٌ قراءةً فقط · **الكتابة:** صفر · **البوّابة:** 🔴 مغلقة
**المصدر:** سلمان — *«لا، ما في سعر 0، هذا الشي مرفوض. خلّي متل ما هو يسأل عن السعر في حال عدم
وجوده. ما عنا product سعرو 0.»*

> هذه الورقةُ مكتوبةٌ ليستأنف منها أيُّ أحدٍ **بلا إعادةِ تحقيق**. كلُّ رقمٍ فيها قراءةٌ حقيقيّةٌ من
> الإنتاج عبر جلسةٍ مختومةٍ للقراءة، أُثبِت ختمُها قبل كلِّ قياسٍ بمحاولةِ كتابةٍ على عمودٍ **موجود**
> (`sort_order`) فرُفِضت: «cannot execute UPDATE in a read-only transaction».

---

## ما طلبه سلمان بالضبط

أن يكون غيابُ السعرِ `NULL` حقيقيّاً بدلَ تحويلِه إلى `0` عند الـAPI العامّ، ثمّ أن يستند منطقُ
«السعر اليومي / اسأل عن السعر» إلى **غيابِ السعرِ نفسِه** بدلَ قائمةِ أسماءِ أقسامٍ مكتوبةٍ في الكود.
خارجَ النطاقِ صراحةً: StoreOrder · سجلّاتُ الزبائن · تخزينُ الأرقام · الدفع · Whish · الصفحةُ
الخاصّة · وأيُّ بيانِ إنتاجٍ يخصّ أرجونا · و`price_label` · و`CatalogTab.jsx`.

---

## Confirmed Findings

### ١ — الصفرُ ليس في القاعدةِ وحدَها: **نحن نصنعه**، ونصفُ المنصّةِ لا يصنعه

| الملفّ | السطر | ماذا يفعل بالعدم |
|---|---|---|
| `app/services/catalog_service.py` | 35 | `float(item.price) if item.price is not None else None` ✅ صادق |
| `app/services/catalog_service.py` | 66 | `float(i.price) if i.price is not None else None` ✅ صادق |
| `app/api/v1/public/restaurant.py` | **30** | `str(item.price) if item.price is not None else "0"` 🔴 **يخترع صفراً** |

مُسلسِلان للعمودِ نفسِه يختلفان، والعامُّ وحدَه هو الكاذب. ⇒ **⑥-أ ليست ميزةً جديدة، بل مواءمةُ
المسارِ العامِّ مع الإداريِّ الذي يقول الحقيقةَ منذ اليوم.**

### ٢ — القاعدةُ والعقدُ يسمحان بالعدمِ أصلاً، وسابقةٌ حيّةٌ تعمل

```
information_schema: catalog_items.price  numeric  nullable=YES  default=None
prisma/schema.prisma:256                 price  Decimal? @db.Decimal(10,2)
beit-al-fakhar                           34 صنفاً نشطاً بسعرٍ NULL — يعمل اليوم
caracas                                  18 صنفاً بسعرِ 0   ← الشاذُّ الوحيدُ على المنصّة
أيُّ تينانتٍ آخرَ بسعرِ 0                   **صفر**
```
⇒ **لا migration ولا schema جديد.** الحقلُ nullable في الاثنين معاً.

### ٣ — ⑥-أ محايدةٌ تماماً اليوم

صفرُ صفٍّ بسعرِ NULL يمرّ من مسارِ المطاعم الآن (كاراكاس 0 · وbeit-al-fakhar متجرٌ يَرُدّ **403**
على هذا المسار). ⇒ تغييرُ السطرِ 30 لا يغيّر بايتاً واحداً لأيِّ تينانتٍ قبل ⑥-ب.

### ٤ — نقطةُ الفصلِ عند **القسم**، والخادمُ يملك ما يلزم بصفرِ استعلامٍ إضافيّ

```
/menu/categories  →  _fmt_category(include_items=False)
   يُرجع: id · name_ar · name_en · image_url · fallback_image_url · item_count · sort_order
   **ولا يُرجع الأصناف**  ⇒  الواجهةُ لا تعرف الأسعارَ لحظةَ فصلِ الشريط
   لكنّ list_menu_categories(include_items=True) محمَّلٌ أصلاً لحسابِ fallback_image_url وitem_count
   ⇒ «كم صنفاً له سعر» يُحسَب من صفوفٍ في الذاكرةِ سلفاً
```
⇒ الإضافةُ المقترحة: حقلٌ مشتقٌّ واحدٌ `priced_item_count` في `_fmt_category` — **إضافيٌّ لا كاسر**،
ويصل المسارَين معاً (`/menu` و`/menu/categories`) لأنّهما يشتركان في المُسلسِل نفسِه.

### ٥ — «قسمٌ بلا أسعار» يعزل القسمَين بلا لبس، **بشرطٍ واحد**

```
ساندويش 25/25 · جوانح 3/3 · برغر لحم 6/6 · تشكن برغر 4/4 · وجبات 17/17
مازة 7/7 · مقبلات 3/3 · مشروبات باردة 10/10 · ترويقة 14/14 · كوشينيا 8/8 (مخفيّ)
متبلات(1كغ)        items=10  priced=0   ← الوحيدان
قطع دجاج نيء(1كغ)  items=8   priced=0
ساندويش شرقي · وجبات مميزة   items=0  priced=0   ← **قسمان فارغان**
```
🔴 القسمان الفارغان يطابقان «صفرُ مسعَّر» أيضاً ⇒ **الشرطُ لازم يكون `item_count > 0 &&
priced_item_count === 0`**، وإلّا صُنّفا يوميَّين خطأً.

### ٦ — ⑥-د: `DAILY_PRICE_CATEGORIES` ليست تجريداً مشترَكاً

ستُّ إشاراتٍ، **كلُّها داخل `frontend/src/pages/caracas/normal/MenuPage.jsx`** (154 · 155 · 468 ·
469 · 470 · 505). صفرُ مستهلكٍ خارجَ كاراكاس. ⇒ تصير dead code بعد ⑥-ج وتُحذَف محلّيّاً، ولا
يُحذَف شيءٌ مشترَك.

## Side Findings — سُجِّلت ولم تُمَسّ

### أ — محمود **لا يستطيع إفراغَ سعرٍ** من لوحتِه إطلاقاً

```javascript
// frontend/src/pages/generic-admin/tabs/CatalogTab.jsx:271-274
price: itemForm.price !== '' ? parseFloat(itemForm.price) : undefined,
if (body.price === undefined) delete body.price      // ← المفتاحُ يُحذَف، فالقيمةُ القديمةُ تبقى
```
حقلٌ فارغٌ لا يكتب `NULL` ولا `0` — **لا يكتب شيئاً**. فلا طريقَ في الواجهةِ لقولِ «هذا الصنفُ بلا
سعر». خارجَ ⑥ بقرارِ سلمان، ومرتبطٌ بقرارِ `price_label` المؤجَّل.

### ب — قاعدةُ التخزينِ تسمّي مشروعاً غيرَ الذي يخدم الإنتاج

`.claude/rules/storage-tenant.md §3` يذكر `wefjghagwpkotrrdiqyi.supabase.co`، والإنتاجُ يخدم
**٣٥/٣٥ صورةٍ** من `qjocpqokwmlpzaftltiy.supabase.co`. وثيقةٌ تحكم الكتابةَ وتسمّي مضيفاً خطأً.
