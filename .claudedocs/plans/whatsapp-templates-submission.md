# قوالب واتساب — نصوص الطلب لميتا

> **المرحلة:** Phase 3 (G5). **الحالة:** جاهزة للتقديم — **ما انبعتت بعد.**
> **التقديم قرار سلمان وحده.** ما تنشأ ولا تعدَّل على ميتا بدون كلمة صريحة.
> **الجاهزية مؤكَّدة 2026-09-11:** WABA صحيح · `quality_rating = GREEN` · الرقم `VERIFIED`.

---

## قبل ما تبلّش — ثلاث حقائق بتوفّر أسابيع

**١. القوالب بتنعتمد بالتوازي.** تقديم ثلاثة مع بعض بيكلّف نفس وقت تقديم واحد. تقديمهن
بالتتابع بيضرب الانتظار بثلاثة. **قدّمهن كلهن بجلسة وحدة.**

**٢. أشيع سبب رفض هو الأمثلة، مش النصّ.** ميتا بتطلب قيمة مثال لكل متغيّر، وبترفض إذا كانت
ناقصة أو غير منطقية (`test`، `123`، `aaa`). الأمثلة تحت **حقيقية الشكل** ومقصودة هيك.

**٣. تعديل قالب معتمد = دورة اعتماد جديدة.** فأي زرّ أو حقل ناقص اليوم بيكلّف أسابيع لاحقاً،
مش دقايق. لهيك الأزرار موجودة من الآن — راجع القرار الوحيد المفتوح تحت.

### قواعد ميتا يلي بتحكم الصياغة تحت
- **الاسم:** حروف صغيرة وأرقام وشرطة سفلية فقط.
- **الفئة:** `UTILITY` — تحديث معاملة. (لو ميتا أعادت تصنيفه `MARKETING`، بيتغيّر التسعير
  وقواعد الانسحاب — راقب التصنيف بالردّ، مش بس القبول/الرفض.)
- **المتغيّرات:** مرقّمة تسلسلياً من `{{1}}`، و**النصّ ما بيبدأ ولا بينتهي بمتغيّر**.
  كل القوالب تحت بتنتهي بنصّ ثابت لهالسبب بالذات.
- **ما في قيمة فاضية:** متغيّر بدون قيمة بيفشل الإرسال. الكود لازم يبعت `—` بدل الفراغ.

## القرار الوحيد المفتوح — أزرار قالب التاجر

الأزرار بتستقبلها `_extract_message` (G8، شغل Phase 3)، بس **تفعيل الإجراء** نفسه
(مين مسموح يأكّد) هو Phase 4 ولسا بدّو نموذج صلاحيات و G10.

| | مع الأزرار | بدون الأزرار |
|---|---|---|
| دورة اعتماد | **وحدة** | **اتنين** — أسابيع إضافية لاحقاً |
| خطر | زرّ موجود قبل ما ينشتغل | ولا خطر |

**التوصية: ضعها الآن.** لأن D8 **مصادق عليه**: التاجر بيتصرّف من رسالة واتساب، ما في تقويم
بالـv1. فالأزرار مش استباق — هي الآلية المقرّرة. والضمانة إنو G8 **ما بتفعّل الإجراء** لحد
ما Phase 4 تفتح؛ لحد وقتها الضغطة بترجّع ردّاً واضحاً بدل صمت.

## القالب ١ — تنبيه حجز جديد للتاجر ⭐ الأولوية

```
الاسم    : new_reservation_alert
الفئة    : UTILITY
اللغة    : Arabic (ar)
الترويسة : بدون
```

**النصّ:** *(اسم المحل صار `{{1}}` — طلب سلمان 2026-09-11)*
```
🔔 حجز جديد عند {{1}}

الزبون: {{2}}
الرقم: {{3}}
الخدمة: {{4}}
الموظف: {{5}}
الموعد: {{6}}
رقم الحجز: {{7}}

اضغط تأكيد ليصل الإشعار للزبون.
```

**التذييل:** `عبر SalmanSaas`

**الأزرار:** `Quick reply` × 2 → **`تأكيد`** · **`إلغاء`**

**الأمثلة (إلزامية):**
| | | | |
|---|---|---|---|
| `{{1}}` | `RK Barber Shop` | `{{5}}` | `جعفر` |
| `{{2}}` | `حسين رقا` | `{{6}}` | `2026-09-15 16:30` |
| `{{3}}` | `96170985212` | `{{7}}` | `BF948302` |
| `{{4}}` | `قص شعر` | | |

**ليش اسم المحل أولاً:** الرسالة جاية من **الرقم السنترال**، فالتاجر بيشوف هوية المنصّة لا
هوية محلّه. بدونه الرسالة مش مفهومة لحالها — خصوصاً لصاحب أكتر من محل.

**ليش بلا إيموجي بعد الاسم:** 💈 خاصة بالحلاقة. لو انحطّت بالنصّ الثابت بتوصل لمطعم كمان.
إذا بدها إيموجي حسب الفئة، بتنضاف **جوّا قيمة `{{1}}`** وقت الإرسال، مش بالقالب.

> ### 🔴 فجوتان بالكود لازم تنسدّا قبل أول إرسال بهالقالب
>
> **١. `client_name` مش موجود أصلاً بالدالة.** `send_new_reservation_to_merchant()`
> (`whatsapp_notifications.py:269`) بتاخد ٨ وسائط، **ما فيها اسم المحل** — لازم وسيط جديد.
> `_notify_reservation_event()` بتحلّه أصلاً (`reservation_service.py:182`)، فمصدره جاهز.
>
> **٢. القالب ما بيقدر يحذف سطر.** الكود اليوم بيحذف سطر الخدمة أو الموظف إذا فاضي، وميتا
> بترفض متغيّر بقيمة فاضية. **لازم يبعت `—`.**
>
> **وقرار صغير مرافق:** الكود بياخد `client.name` (الإنكليزي) مش `name_ar`. القيم الحقيقية:
> `rk → RK Barber Shop` · `mr-h → Salon, Mister H` (وعندو `صالون مستر إتش`) ·
> `barberlab-test → بربرلاب`. **`name_ar or name` بتقرأ أطبع برسالة عربية** — قرار مش منفَّذ.

## بعد التقديم

| | |
|---|---|
| **عندك** | مراقبة الحالة: `PENDING` → `APPROVED` / `REJECTED`. **راقب الفئة كمان** — إعادة تصنيف لـ`MARKETING` بتغيّر القواعد بدون ما ينرفض الطلب |
| **عنا** | **G8** — `_extract_message` لسا بترجّع `unknown` لردّ زرّ القالب (`type: "button"`، مش `interactive.button_reply`). بدونها التاجر بيضغط تأكيد وما بيصير شي |
| **وبعدها** | إرسال بقالب: `whatsapp_service` بيبعت `text` فقط اليوم — بدّو مسار `template` بمكوّناته |

**الاتنين بيمشوا بالتوازي.** التقديم بيبلّش الساعة عند ميتا؛ شغل الكود ما بيستنى حدا.
