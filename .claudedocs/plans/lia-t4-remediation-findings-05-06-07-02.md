## 7 · R3 — Finding 07

### الترتيبُ الحاليّ في `_entry_family` (~:200-250)

```
١ طولٌ < 6 ⇒ None        ٢ لا فعلَ إدخال ⇒ None
٣ الأسماء: service(خدمة/خدمه/سيرفس/service/+فرانكو) · product(…) · booking(موعد/مواعيد/حجز/…)
٤ أكثرُ من اسم ⇒ _AMBIGUOUS          ٥ اسمٌ واحد ⇒ عائلتُه
٦ لا اسم + فعلُ تسجيل ⇒ create_reservation   ٧ لا اسم + فعلُ إضافة + حمولة ⇒ _AMBIGUOUS
```

**الخلل:** الخطوة ٤ تعدّ الأسماءَ ولا ترى الفعل. «سجل» + «موعد» = نيّةٌ صريحة، و«خدمة» عابرة.

### أصغرُ قاعدةٍ حتميّة

```
قبل الخطوة ٤ مباشرة:
   if فعلُ_تسجيل and اسمُ_موعد:  return "create_reservation"
```

- **لا توسيعَ لأيِّ قائمةِ كلمات.** القاعدةُ تُعيد ترتيبَ أولويّةٍ فقط.
- **محصورةٌ بفعلِ التسجيل** عمداً: «ضيف موعد وخدمة» (فعلُ إضافة) **يبقى _AMBIGUOUS** ⇐ التأكيدان
  القائمان في `test_lia_reservation_t4.py:176` و`test_lia_product_s3.py:226` **لا يتغيّران.**
- ما يتغيّر: «سجل موعد … خدمة …» ⇐ حجز (الحالةُ الحيّةُ الفاشلة) · «سجل موعد … منتج …» ⇐ حجز.
- ⚠️ **نقطةُ قرار:** هل «سجل موعد … بضاعة» حجزٌ فعلاً؟ الترشيح: نعم — «سجل موعد» صريحة.
