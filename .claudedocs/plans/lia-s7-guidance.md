## ٢ · 🔴 القياسُ الذي يُغيّر البندَ الثاني

طُلب أن يتعامل Lia مع المنتج «كـProduct حقيقيٍّ له بياناتُه الموجودةُ فعلاً، بما فيها الحقولُ
الجاهزةُ حالياً مثل الكمية/الأحجام/الألوان». **فُحِص الـschema والخدمةُ والواجهةُ والإنتاج:**

### ما يملكه `CatalogItem` فعلاً (`prisma/schema.prisma:496-525`)

```
nameAr · nameEn · descriptionAr · descriptionEn · imageUrl · price · currency
isActive · isFeatured · sortOrder · categoryId · metadata(Json?) · createdAt · updatedAt
```

```
🔴 لا عمودَ كمّيّة.  لا مخزون.  لا حجم.  لا لون.  ولا واحدٌ منها موجودٌ في الـschema.
```

### وما تكتبه `admin_update_item` — وهي المسارُ القائمُ الوحيد

أحدَ عشرَ حقلاً + `metadata`، وتُسقِط كلَّ `None` فالتحديثُ الجزئيُّ يعمل:

```
name_ar · name_en · description_ar · description_en · image_url · price · currency
is_featured · is_active · sort_order · category_id · metadata
```

### و`metadata` ليست عقداً — مقيسةً على الإنتاج

```
١٨٠ صفَّ CatalogItem على المنصّةِ كلِّها  ·  ثلاثةٌ فقط تحمل أيَّ metadata
والمفاتيح:  fabric · images · discount · variants · style_code · compare_at_price
            ⇒ شكلٌ خاصٌّ بتينانتِ أزياء، ولا واحدٌ منها كمّيّةٌ أو مخزون

ومن يقرأ مفاتيحَ metadata لمنتج؟   قراءةٌ **واحدة** في المستودعِ كلِّه:
   frontend/src/pages/olivello/sections/ProductsSection.jsx:116   metadata?.size
   ⇒ صفحةُ تينانتٍ مخصَّصةٌ واحدة، لا سطحُ المتجرِ العامّ الذي تستعمله محلّاتُ الحلاقة
```

### 🔴 و`quantity` الموجودةُ فعلاً شيءٌ آخرُ تماماً

```
StoreCartItem.quantity   =  كم يشتري **الزبون** من الصنف في سلّته
                            وليست «كم بالمخزون». لا علاقةَ بينهما.
```

**⇒ فـ«الكمية/الأحجام/الألوان» ليست «حقولاً جاهزة».** والمخزونُ غائبٌ بنيويّاً — وهو مُسجَّلٌ
أصلاً في `lia-product-entry.md` §2.3. وهذا بالحرف ما يستدعيه **القرارُ ٧**: يتوقّف ويحتاج قراراً
مستقلّاً، ولا يُخترَع داخل S7.

## ٣ · A1 · التكرار — الإرشادُ والاختيار

**الغرضُ المُعلَن: توعيةُ المالكِ، لا منعُ صفٍّ مكرَّر.**

### والتكرارُ أوسعُ من Lia — مقيسٌ على الإنتاج

```
خمسةُ أزواجٍ مكرَّرةٍ نشطةٌ الآن:
   «مشط خشب» ×2                 ← barberlab-test، من اختبارِ ١٧ أيلول
   «كوشينيا جبنة وسجق» ×2  ·  «كوشينيا لحمة مفرومة» ×2  ·  «صحن حمص» ×2  ·  «سودة» ×2
                                ← أصنافُ مطاعمَ، **أقدمُ من Lia بكثير**
⇒ الثغرةُ في المنصّة (لا فحصَ تكرارٍ في أيِّ مسار)، وLia جعلتها جملةً واحدة.
   وتحصينُ اللوحةِ خارجُ النطاق — Finding مُسجَّل.
```

### العقد

```
عند اسمٍ موجود (مطابقةً على العربيّةِ المطويّة، تينانت-wide):
   ١  يُخبَر المالكُ أنّه موجود، **وتُعرَض بياناتُه الأساسيّةُ والقسمُ الذي فيه**
   ٢  ثمّ اختيارٌ صريح:   عدّل الموجود   ·   صنف تاني بنفس الاسم   ·   إلغاء
   ٣  ولا كتابةَ قبل الاختيار
```

### وماذا يعني «عدّل الموجود» — بعد القياس

```
✅ داخلَ المسارِ القائم (admin_update_item · عمليةُ update_product المسجَّلة):
      السعر · العملة · الاسمُ العربيُّ والإنجليزيّ · الوصف · التمييز (isFeatured)
      التعطيل (isActive) · الترتيب · **ونقلُ القسم (category_id)**

🟡 metadata: تُمرَّر **كُتلةً معتمةً** إن مُرِّرت أصلاً — ولا مفتاحَ فيها يُفترَض اسمُه،
      لأنّ ثلاثةَ صفوفٍ فقط تحملها ولا شيءَ عامٌّ يقرؤها.

🔴 خارجَ المسارِ القائم، ويتوقّف: الكمّيّة · المخزون · الأحجام · الألوان · الصورة
      (الصورةُ عمودٌ موجود، لكنّ رفعَها من الواتساب ساقٌ غيرُ مبنيّة — بندٌ منفصلٌ مُسجَّل)
```

**وفي هذه الشريحةِ تُنفَّذ أوّلاً: السعرُ والاسمُ والقسم.** والبقيّةُ متاحةٌ بالعقدِ نفسِه، وتُفتَح
بترتيبك — ولا تُبنى واجهةُ محادثةٍ لثمانيةِ حقولٍ قبل أن يُطلَب.

## ٤ · A2 · Franco Arabic — فهمٌ لا واجهة

**المطلوب:** أن يفهم Lia ما يكتبه المالكُ فعلاً، وفيه الفرانكو بالحروفِ اللاتينيّةِ والأرقام
(`3`=ع · `7`=ح · `2`=ء · `5`=خ). **وليس** تحويلَ الردودِ إلى فرانكو.

### وأين يقع العملُ فعلاً — قطعتان لا نظامُ لغة

```
١  البوّابةُ الرخيصة   مطابقةُ نصوصٍ حرفيّة ⇒ **هنا العمل**
                     تُوسَّع قوائمُ الأفعالِ والأسماءِ بتهجئاتِ الفرانكو الشائعة
                     مثل  dif / dayef / dayif / add   و  mantoj / bde3a / menteg / product
                     ⇒ توسيعُ قائمةٍ قائمة، **لا parser**

٢  النموذج          يقرأ الفرانكو أصلاً بلا تدريب. فالمطلوبُ **سطرٌ في prompt البضاعة**
                     يقول إنّ الإدخالَ قد يكون فرانكو، وإنّ `name_ar` يُعاد **بالعربيّة**.
                     ⇒ لا كتلةَ prompt جديدة
```

### 🔴 وقيدٌ لا يُخترَق

```
الفعلُ يبقى شرطاً لكلِّ المسارات.
وكلُّ تهجئةٍ تُضاف تُختبَر ضدَّ رسائلِ **زبونٍ** بالفرانكو («bade e7jaz da8n») — فتوسيعُ
القائمةِ بلا هذا الفحصِ يفتح بوّابةَ المالكِ لرسائلِ الزبائن، وهو العطبُ الذي أمسكته
الحزمةُ القائمةُ أمسِ على كودي.
```
