## Change

One file, additive only — no backend, no schema, no DB, no new mutation path:

- **`ReservationsTodayView.jsx`** — new `TodayAgendaPanel` component: a compact, time-sorted list
  of the day's real bookings across every real barber (not scoped to whichever columns are
  currently toggled visible — the panel's whole point is one full-picture summary, same reasoning
  the grid itself doesn't apply). Renders beside the grid (grid first in DOM order so it lands on
  the RTL reading-start/right side, panel trailing/visually left — mirrors the reviewed
  screenshot's own grid-primary/agenda-secondary relationship). Reuses `StatusBadge`/`STATUS_META`
  (imported from `ReservationsTab.jsx`, already exported) and the exact same `ReservationPopover`
  every card in this file already opens via the same `onOpen` callback shape — no new component,
  no new data fetch (reads the same already-fetched `items`).
