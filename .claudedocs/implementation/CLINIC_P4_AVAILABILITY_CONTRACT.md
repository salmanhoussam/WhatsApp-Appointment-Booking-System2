## §٠ — الهدف

```
من:   Service/Motif يقول المدّة والشروط                     ← P3 ✅
إلى:  Resource + working hours + existing reservations + duration  →  available slots
```

والمسار: `Patient → Service/Motif → Doctor(Resource) → Date → slots`.

**والحجزُ النهائيُّ يستعمل منطقَ التوفّر نفسَه** — لا محرّكٌ للموقع وآخرُ لواتساب لاحقاً.

### التقسيم

```
P4-A  تحقيق        ✅ منجَز (قراءةً فقط)
P4-B  العقد        ← هذه الوثيقة
P4-C  التنفيذ      محرّكٌ مبنيٌّ على المورد، بلا كسر الحلاق
P4-D  الـAPI        نقطةُ توفّرٍ للعيادة
P4-E  أمانُ السباق  تزامنٌ + تفرّدُ DB + فشلٌ حتميّ
P4-F  البوّابة
```

## §١ — العقد: فصلُ **البحث** عن **الحساب**

هذه هي الفكرةُ كلُّها، وهي مُقَرَّةٌ سلفاً في C4.3:

```
البحثُ عن مالك التقويم     يبقى لكلّ جدولٍ على حدة   (Barber / Resource — جدولان، لا يُوحَّدان)
حسابُ الأوقات               يصير واحداً               (ساعات + حجوزاتُ اليوم + مدّة ⇒ slots)
```

**ممنوعٌ `get_clinic_slots` توأماً لـ`get_available_slots`** — هذا تكرارُ خطأ الحلاق حرفيّاً.
**وممنوعٌ توحيدُ `Barber` و`Resource` في جدول** — ذاك تغييرٌ في الحلاقة.

المحرّكُ يأخذ **الحالةَ المحلولة**، لا معرّفَ جدول. الدوالُّ القائمةُ تصير أغلفةً رفيعةً فوقه،
وسلوكُها محفوظٌ بالتعريف — ويُثبَت بـRG-6، لا يُفترَض.

**والتوقيعُ النهائيُّ لا يُثبَّت هنا** (قرارُك في P1). يخرج من التنفيذ، بشرطِ أن يحترم الفصلَ أعلاه.

### السلسلة التي يجب أن ينفّذها العقد

```
Service          →  durationMin  (خادميّاً — ق-٤-أ)
   ↓
eligible Resources  →  ResourceService  (ق-٤-ب)
   ↓
Resource working hours  →  Resource.workingHours  [→ Client.config؟ ق-٤-د]
   ↓
existing reservations   →  استعلامُ يومٍ واحد، status IN (pending, confirmed, arrived)
   ↓
duration + slot step    →  ق-٤-ج
   ↓
valid slots
```

## §٦ — 🔴 P4-E · اختبارُ السباق يحتاج قراراً منفصلاً

**الفهرسُ موجودٌ منذ P1 ومُثبَتٌ بنيويّاً. إغلاقُه للسباق غيرُ مُثبَتٍ حيّاً، ولا يُدَّعى.**

وإثباتُه يحتاج **حجزَ عيادةٍ حقيقيّاً** ⇒ **تينانتَ عيادةٍ** ⇒ **كتابةَ إنتاج**.

```
الخيار ١   فحصُ تزامنٍ محلّيٌّ بقاعدةٍ مزيَّفة       ⇒ يثبت الترجمةَ والفرع، لا ذرّيّةَ Postgres
الخيار ٢   تينانتُ عيادةٍ حقيقيّ + طلبان متزامنان   ⇒ يثبت الشيءَ نفسَه — ويحتاج موافقتَك
```

**توصيتي:** الخيار ١ داخل P4 (يغلق AV-8 كما يمكن إغلاقُه محلّيّاً)، **والخيار ٢ بعقدٍ منفصلٍ
لتينانت الاختبار** — وهو نفسُه ما يغلق P1-U1 و P2-U1 و P3-U1 دفعةً واحدة. **ولا يُخلَط بـP4.**
